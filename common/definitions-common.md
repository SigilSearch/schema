# 共通用語の定義

## 素体
以下のトリプルを指す：
1. ベースメッシュ
2. リグ（Humanoid 互換のボーンマップを含み得る）
3. マテリアルのテクスチャをサンプリングする際に使用される UV セット（UV0..n）

## アバター
VRSNS 上でユーザーを表象し、当該ユーザーの入力に応じて挙動する Humanoid/非 Humanoid の 3D 構成体。

## アイテム
当該 VRSNS/エディタに取り込め、アバターまたはワールドに適用可能なデジタルアセットの総称。

例：
* 3D モデル
* テクスチャ
* マテリアル
* シェーダー
* スクリプト
* アニメーション

### 適用形態（Axis）
* Apply: 見た目・挙動を変更する非アタッチ型（例：テクスチャ、マテリアル、シェーダー、アニメーション）
* Wear: アバターにアタッチされ表示/物理/挙動を伴う 3D オブジェクト
* Replace: 素体の一部を置換するアイテム（耳/尻尾/義肢/顔パーツ等）

## 3D モデル
メッシュ（頂点/法線/UV）を主とするジオメトリデータ。必要に応じてスキン/ボーン/ブレンドシェイプ/マテリアル等を含む。

## 着用可能アイテム（Wear）
アバターにアタッチされ、表示/物理/挙動を伴う 3D オブジェクト。  
（※ パーティクル/VFX等の非メッシュ要素を含む場合がある）

### 衣類判定に用いる補助定義
* 皮膚可視領域: 素体のスキン領域マスク（顔/胴/上肢/下肢などのサブ領域を含む）
* 有効遮蔽率 V: `V = (α ≥ α_min の skin_pixels) / (all_skin_pixels)`  
  ※ α_min は 0 < α_min ≤ 1 の閾値。領域ごとに別値を許容。

## 布
着用可能アイテムのうち、**皮膚可視領域に対して有効遮蔽率 V が 0 を超える**ものの総称。  
（= 皮膚を少しでも隠す/重ねる機能を持つもの。素材表現は不問）

## 服
布のうち、**有効遮蔽率 V が閾値 k_1 以上**のもの。

## アクセサリー
着用可能アイテムのうち、**有効遮蔽率 V が閾値 k_1 未満**で、主目的が装飾であるもの。  

例:
* チョーカー
* メガネ
* ピアス
* 腕輪

## ヘアモデル
頭部に装着し、髪型を変更する着用可能アイテム。
衣類・アクセサリーとは別カテゴリ。

## プロップ（Prop）
手持ち/背負い/装着される道具類。

例:
* マイク
* 武器
* 楽器
* バッグ

衣類・アクセサリー・ヘアモデルに含めない。

## 置換パーツ（Replace）
素体の一部（メッシュ/ボーン/マテリアル構成）を**置換**するアイテム。

例:
* 獣耳
* 尻尾
* 義肢
* 顔

## テクスチャ
適用可能アイテムの見た目に直接的または間接的に影響を与える画像ファイルの総称。  

例:
* アルベド
* ノーマルマップ
* マスクテクスチャ
* SDFテクスチャ
* MSDFテクスチャ
* SVGファイル
* デカール

## アイテクスチャ
Humanoid 素体の**目領域**に適用するテクスチャ。

## メイクテクスチャ
Humanoid 素体の**顔領域**に適用するテクスチャ（チーク/リップ/眉/まつげマスク等を含み得る）。

## VRSNS
HMD を含む各種クライアントで参加でき、ログイン後にユーザー同士が交流可能な**持続的オンライン空間**をホストするサービスの総称。  
例：VRChat / Cluster / Resonite

## BodySpec

アバター間で素体の一部を共有する場合、その共有関係を明示するために BodySpec を定義する。

定義:
あるアバター α の素体における胴体メッシュおよび対応するボーン構造が、別のアバター β の素体と同一または互換であるとき、  
「α の BodySpec は β である」と表現する。

このとき β が自己の素体を基準として定義されている場合、「β の BodySpec は β である」とする。  
すなわち BodySpec は自己参照を許す。

型:
```scala
opaque type BodySpec_rel = Rel[Avatar, BodySpec]
```

備考:
BodySpec は着用可能アイテムおよび適用可能アイテムの互換検索において重要な参照プロパティである。
同一の BodySpec を持つアバター間では、衣装やテクスチャの流用が高い確率で成功する。

例: 
* `エク: Avatar`
* `真冬: Avatar`
* このとき、「エクのBodySpecは真冬である」という文が成り立つ。
* 同時に、「真冬のBodySpecは真冬である」という文も同時に成り立つ。
