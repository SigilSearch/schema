### 命名規則

```text
Sitemap: https://public-files.gumroad.com/sitemap/products/monthly/2025/4/sitemap.xml.gz
Sitemap: https://public-files.gumroad.com/sitemap/products/monthly/2025/4/sitemap1.xml.gz
Sitemap: https://public-files.gumroad.com/sitemap/products/monthly/2025/4/sitemap2.xml.gz
Sitemap: https://public-files.gumroad.com/sitemap/products/monthly/2025/4/sitemap3.xml.gz
Sitemap: https://public-files.gumroad.com/sitemap/products/monthly/2025/4/sitemap4.xml.gz
```

### 構造

gzip 圧縮された XML。

スキーマは一般的な [sitemap](https://www.sitemaps.org/protocol.html)。

`url.loc` がリダイレクトになっていることに注意。`changefreq` は `daily`。
また、`image:image` は存在しないこともある。
